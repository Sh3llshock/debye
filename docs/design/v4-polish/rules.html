AI usually does this, Debye does this

Each row shows the default that AI tools ship and the rule the Debye screens follow instead, both drawn live on this page. The left column is the generic look on purpose. The rules apply to every page in the mockups and to the build in step 4.

Typeface

v0, Lovable and Claude Code all start from Inter, so it reads as "default"
AI default
Inter or Geist on everything
Debye
Lexend, everywhere

Lexend was designed to be easier to read, with wider letters and open spacing. That suits tenants writing in a second language, typing on a phone at night. Sizes sit one step smaller because it runs wide.

Corners

"Rounded corners on everything" is the most-cited tell
AI default
12–16 px on every card, input and image
Debye
2 px tags, 3 px controls, 4 px panels

Square-ish, like a case file and a job sheet. The one exception is WhatsApp bubbles (6 px), which stay recognisable as WhatsApp.

Buttons

Gradient pills with a glow, or rounded-lg with an icon and a "→"
AI default
Get started →
Debye
Handle it myself

Rectangles with a key edge. The primary is solid wine with a darker 2 px bottom edge and moves down 1 px when pressed. The secondary is an ink outline, and the third level is an underlined link. Labels name the action, with no arrows.

Type scale

121416182430
Debye

A modular scale with a ratio of about 1.22, weights 300 / 400 / 500. The one large figure per screen (the price) is 32.

Focus and hover

A blurry indigo glow ring, and cards that lift and grow on hover
AI default
Focused
Debye
Focused

A crisp 2 px square outline in wine. Hover changes colour only, and press moves the button 1 px down. Nothing scales or floats.

Colour

Indigo or violet primary, gradient washes
AI default
Debye

The client's wine as the only action colour, on warm paper. Green, orange and blue only mark state, as small markers.

Copy

"Welcome back! 👋", exclamation marks, "A · B · C" meta strings
AI default
Good morning, Luka! 👋 · 3 cases · 2 new
Debye
What's wrong at home, Luka?

The heading names the task. Meta facts are separated by space, not dots. No emoji and no exclamation marks.

Research (community guides and skill rule sets, not measured studies; sources disagree on details):
  • UX Collective: AI design isn't ugly, it's fluent (Inter, shadcn and Lucide as shipped defaults)
  • DEV: users can tell when your UI was AI-generated (primary colour, radius and font as the fastest fixes)
  • ux-skill wiki: how to detect AI slop (Inter, the Tailwind type scale)
  • Unslop UI playbook (rounded corners on everything, indigo primaries, gradient text)
  • impeccable anti-patterns (eyebrows, side stripes, cards in cards, glyphs as icons)
  • Google Fonts: about Lexend (made by Bonnie Shaver-Troup and Thomas Jockin to reduce visual stress when reading; the published evidence is small, so we choose it for character and openness, not as a proven reading aid)
